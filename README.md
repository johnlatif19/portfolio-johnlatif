# John Latif Portfolio

## 🚀 Professional Front-end Developer Portfolio

A modern, production-ready portfolio website built with React, TypeScript, and cutting-edge web technologies.

## ✨ Features

- **Interactive 3D Hero** - Using React Three Fiber for immersive experience
- **Smooth Animations** - Framer Motion for fluid transitions
- **Typewriter Effect** - Dynamic text animations
- **Responsive Design** - Optimized for all devices
- **Performance Optimized** - Lazy loading and code splitting
- **Accessibility** - Semantic HTML and ARIA labels
- **Dark Mode** - Elegant dark theme with accent color

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- React Typewriter Effect

## 📦 Installation

```bash
# Clone repository
git clone [your-repo-url]

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
